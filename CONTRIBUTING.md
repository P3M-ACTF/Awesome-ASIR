# Contribuir a Awesome-ASIR

Gracias por ayudar a mantener una biblioteca pequeña y útil.

1. Consulta el [catálogo](README.md) y los [criterios](docs/CRITERIOS.md); busca duplicados.
2. Abre una issue si quieres debatir una incorporación. Para una corrección clara puedes enviar directamente una PR.
3. Edita el archivo de la categoría principal en `recursos/`. Una ficha por recurso; orden alfabético por nombre visible.
4. Usa la plantilla siguiente y el [vocabulario](docs/ETIQUETAS.md). Describe el valor educativo en una o dos frases, sin publicidad.
5. Comprueba enlace, requisitos y una muestra del contenido. Indica la fecha real y cualquier limitación de la revisión.
6. Revisa enlaces relativos y anclas si renombras una ficha. Actualiza las rutas del README solo cuando sea necesario.
7. Envía una PR con una incorporación o un conjunto pequeño y coherente de cambios.

## Formato de ficha

```markdown
<a id="identificador-estable"></a>
### [Nombre del recurso](https://dominio.example/ruta)

Descripción breve del aprendizaje y de su valor diferencial.

`Ciclo: ASIR · CE` · `Área: sistemas · bastionado` · `Nivel: Intermedio`<br>
`Idioma: EN` · `Tipo: documentación` · `Coste: Gratis` · `Fuente: Oficial`

**Acceso:** requisitos y límites relevantes. **Revisión:** AAAA-MM-DD.
```

El dominio de la plantilla es ilustrativo: no debe aparecer en una ficha publicada. Mantén estables las anclas existentes para no romper referencias. Separa los dos grupos de etiquetas con `<br>` y añade la ficha al índice local de su categoría.

## Cambios de acceso y retirada

Para informar de un enlace roto o contenido obsoleto, incluye URL, fecha, comportamiento observado y sustitución, si existe. Distingue un bloqueo automatizado de una baja real. Sigue el [procedimiento de mantenimiento](docs/MANTENIMIENTO.md).

## Autoría y trato

Redacta con tus propias palabras, atribuye las fuentes y mantén una conversación respetuosa. Al contribuir aceptas publicar tu aportación original bajo [CC BY-SA 4.0](LICENSE.md). No copies contenido ajeno sin una licencia compatible.
