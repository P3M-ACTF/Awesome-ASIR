## Cómo leer las etiquetas

Cada ficha indica **Ciclo · Área · Nivel · Idioma · Tipo · Coste · Fuente**, además del acceso y la fecha de revisión. El [vocabulario de etiquetas](docs/ETIQUETAS.md) define los valores y sus límites.

- **Gratis**: el material seleccionado no exige pago; puede requerir cuenta o infraestructura propia.
- **Mixto**: combina contenido gratuito con formación, laboratorios o servicios de pago.
- **Condicionado**: acceso sujeto a centro educativo, matrícula o elegibilidad.
- **Certificación** describe preparación; no implica examen gratuito ni una titulación oficial.

Los niveles y la afinidad con los ciclos son valoraciones editoriales. El idioma puede variar por módulo. Las condiciones de las plataformas pueden cambiar: revisa el acceso antes de planificar una práctica.
