## Recursos

<a id="cyberdefenders"></a>
### [CyberDefenders — Blue Team Labs](https://cyberdefenders.org/blue-team-labs/)

Investigaciones prácticas de defensa y análisis forense. Permite trabajar con evidencias y responder preguntas sobre incidentes, más allá de memorizar herramientas.

`Ciclo: ASIR · CE` · `Área: defensa · forense` · `Nivel: Intermedio–Avanzado`<br>
`Idioma: EN` · `Tipo: lab` · `Coste: Mixto` · `Fuente: Oficial`

**Acceso:** cuenta; laboratorios gratuitos limitados y planes de pago. Formación de certificación y exámenes tienen condiciones propias. **Revisión:** 2026-09-18.

<a id="mitre-attack"></a>
### [MITRE ATT&CK](https://attack.mitre.org/)

Base de conocimiento sobre tácticas y técnicas adversarias. Útil para describir comportamientos observados, relacionar evidencias y plantear detecciones; no es un curso introductorio ni una lista de controles de cumplimiento.

`Ciclo: ASIR · CE` · `Área: defensa · hacking-etico` · `Nivel: Intermedio–Avanzado`<br>
`Idioma: EN` · `Tipo: documentación` · `Coste: Gratis` · `Fuente: Oficial`

**Acceso:** consulta pública; anotar identificadores y versión cuando se use en informes, pues las técnicas evolucionan. **Revisión:** 2026-09-18.

<a id="ost2"></a>
### [OpenSecurityTraining2 — OST2](https://ost2.fyi/)

Cursos profundos de arquitectura, ensamblador, depuración e ingeniería inversa. Adecuados para estudiar los fundamentos de bajo nivel necesarios para analizar binarios y vulnerabilidades.

`Ciclo: DAM · CE` · `Área: ingenieria-inversa · hacking-etico` · `Nivel: Intermedio–Avanzado`<br>
`Idioma: EN` · `Tipo: teoría · lab` · `Coste: Gratis` · `Fuente: Oficial`

**Acceso:** cursos gratuitos; la plataforma formativa puede requerir cuenta. Revisar prerrequisitos y preparar las herramientas o VM indicadas en cada curso. **Revisión:** 2026-09-18.

<a id="owasp-wstg"></a>
### [OWASP — Web Security Testing Guide](https://owasp.org/projects/web-security-testing-guide)

Metodología y casos de prueba para evaluar la seguridad de aplicaciones web. Referencia para preparar pruebas y documentar resultados, complementaria a los laboratorios de PortSwigger.

`Ciclo: DAW · DAM · CE` · `Área: seguridad-web · hacking-etico` · `Nivel: Intermedio–Avanzado`<br>
`Idioma: EN` · `Tipo: documentación` · `Coste: Gratis` · `Fuente: Oficial`

**Acceso:** consulta abierta. Usar una versión estable y referencias versionadas en trabajos evaluables; el contenido en desarrollo puede cambiar. **Revisión:** 2026-09-18.

<a id="portswigger"></a>
### [PortSwigger Web Security Academy](https://portswigger.net/web-security)

Explicaciones y laboratorios interactivos de vulnerabilidades web. Permite aprender una técnica, observar su efecto en una aplicación preparada y contrastar las medidas de prevención.

`Ciclo: DAW · DAM · CE` · `Área: seguridad-web · hacking-etico` · `Nivel: Inicial–Avanzado`<br>
`Idioma: EN` · `Tipo: teoría · lab` · `Coste: Gratis` · `Fuente: Oficial`

**Acceso:** academia gratuita; cuenta para progreso y laboratorios. Revisar las herramientas de cada ejercicio; algunos pueden recomendar o requerir funcionalidades de Burp Suite Professional. Certificación de pago aparte. **Revisión:** 2026-09-18.

<a id="pwn-college"></a>
### [pwn.college](https://pwn.college/)

Retos progresivos para comprender Linux, memoria, ejecución y seguridad de sistemas. Proyecto educativo vinculado a Arizona State University, útil para desarrollar soltura técnica con la terminal.

`Ciclo: ASIR · DAM · CE` · `Área: sistemas · hacking-etico` · `Nivel: Inicial–Avanzado`<br>
`Idioma: EN` · `Tipo: teoría · lab` · `Coste: Gratis` · `Fuente: Oficial`

**Acceso:** participación gratuita con cuenta para los retos. Seguir el orden de los módulos y las reglas de la plataforma sobre difusión de soluciones. **Revisión:** 2026-09-18.

<a id="security-onion"></a>
### [Security Onion Documentation](https://docs.securityonion.net/)

Documentación para desplegar y operar una plataforma de monitorización y análisis de seguridad. Útil para un laboratorio que conecte registros, alertas y evidencias de red.

`Ciclo: ASIR · CE` · `Área: defensa · forense` · `Nivel: Intermedio–Avanzado`<br>
`Idioma: EN` · `Tipo: documentación · lab` · `Coste: Gratis` · `Fuente: Oficial`

**Acceso:** documentación pública; el laboratorio requiere infraestructura y recursos de CPU, RAM y disco acordes con la guía. Soporte, formación y funciones comerciales aparte. **Revisión:** 2026-09-18.

<a id="splunk"></a>
### [Splunk — Free Training](https://www.splunk.com/en_us/training/free-courses/overview.html)

Cursos gratuitos para introducir la búsqueda y el análisis de datos en Splunk. Complemento para aprender a consultar registros antes de construir investigaciones y detecciones más complejas.

`Ciclo: ASIR · CE` · `Área: defensa` · `Nivel: Inicial–Intermedio`<br>
`Idioma: EN` · `Tipo: teoría` · `Coste: Gratis` · `Fuente: Oficial`

**Acceso:** cuenta para formación; la selección enlazada es gratuita. Catálogo avanzado, exámenes y licencias de producto pueden ser de pago; no se presupone un entorno de prácticas incluido. **Revisión:** 2026-09-18.
