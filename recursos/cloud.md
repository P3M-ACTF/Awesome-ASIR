## Recursos

<a id="aws-educate"></a>
### [AWS Educate](https://aws.amazon.com/education/awseducate)

Introducción guiada a computación, almacenamiento y redes en AWS, con práctica formativa. Adecuado para empezar antes de recorrer catálogos profesionales más extensos.

`Ciclo: ASIR · DAW · DAM` · `Área: cloud · redes` · `Nivel: Inicial`<br>
`Idioma: ES/EN` · `Tipo: teoría · lab` · `Coste: Gratis` · `Fuente: Oficial`

**Acceso:** registro en AWS Educate; no exige tarjeta para los entornos educativos incluidos. Revisar idioma y requisitos de inscripción; no equivale a una cuenta AWS de producción gratuita. **Revisión:** 2026-09-18.

<a id="aws-skill-builder"></a>
### [AWS Skill Builder](https://skillbuilder.aws/)

Rutas técnicas para profundizar en arquitectura, operaciones y seguridad en AWS. Seleccionar un objetivo concreto, como identidad o redes, en lugar de recorrer todo el catálogo.

`Ciclo: ASIR · DAW · DAM · CE` · `Área: cloud · despliegue · defensa` · `Nivel: Inicial–Avanzado`<br>
`Idioma: ES/EN` · `Tipo: teoría · lab · certificación` · `Coste: Mixto` · `Fuente: Oficial`

**Acceso:** cuenta y navegador con JavaScript; contenido digital gratuito y experiencias de suscripción. Exámenes aparte. [Condiciones de formación](https://aws.amazon.com/training/faqs/). **Revisión:** 2026-09-18.

<a id="cloudflare-developers"></a>
### [Cloudflare Developers](https://developers.cloudflare.com/)

Documentación y tutoriales para desplegar servicios y configurar capacidades de red y seguridad de Cloudflare. Complementa los conceptos de Learning Center con procedimientos de producto.

`Ciclo: ASIR · DAW · CE` · `Área: cloud · despliegue · redes` · `Nivel: Intermedio`<br>
`Idioma: EN` · `Tipo: documentación · lab` · `Coste: Gratis` · `Fuente: Oficial`

**Acceso:** documentación abierta; ejecutar tutoriales puede requerir cuenta, dominio o funciones de pago. Revisar límites del producto utilizado. **Revisión:** 2026-09-18.

<a id="google-skills"></a>
### [Google Skills — antes Google Cloud Skills Boost](https://www.skills.google/)

Rutas y laboratorios de Google Cloud para trabajar con infraestructura, datos y seguridad. Permite practicar tareas acotadas con instrucciones y entornos de formación.

`Ciclo: ASIR · DAW · DAM · CE` · `Área: cloud · despliegue` · `Nivel: Inicial–Avanzado`<br>
`Idioma: ES/EN` · `Tipo: teoría · lab · certificación` · `Coste: Mixto` · `Fuente: Oficial`

**Acceso:** cuenta; opciones gratuitas limitadas y laboratorios sujetos a créditos o suscripción. Consultar los [planes](https://www.skills.google/subscriptions). El dominio anterior de Cloud Skills Boost redirige a este portal. **Revisión:** 2026-09-18.

<a id="microsoft-learn"></a>
### [Microsoft Learn](https://learn.microsoft.com/es-es/training/)

Módulos y rutas para Azure, identidad, administración y seguridad del ecosistema Microsoft. Útil para conectar Windows, servicios cloud y operaciones defensivas con una progresión guiada.

`Ciclo: ASIR · DAW · DAM · CE` · `Área: sistemas · cloud · defensa` · `Nivel: Inicial–Avanzado`<br>
`Idioma: ES/EN` · `Tipo: teoría · lab · certificación` · `Coste: Gratis` · `Fuente: Oficial`

**Acceso:** material autodirigido gratuito; cuenta para guardar progreso. Los ejercicios pueden requerir suscripciones o recursos propios; no asumir un sandbox incluido. Exámenes y formación de instructor aparte. **Revisión:** 2026-09-18.
