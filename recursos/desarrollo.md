## Recursos

<a id="freecodecamp"></a>

### [freeCodeCamp](https://www.freecodecamp.org/espanol/)

Currículo práctico de desarrollo web, APIs y bases de datos con ejercicios en el navegador. Buen refuerzo autodirigido en español; los certificados de la plataforma no sustituyen la evaluación del ciclo.

`ASIR · DAW · DAM · desarrollo · bases-de-datos · Inicial–Intermedio · ES/EN · teoría · lab · Gratis · Comunidad`

**Acceso:** cuenta gratuita; preferir el sitio en español y recurrir al inglés si un módulo aún no está traducido. **Revisión:** 2026-09-21.

<a id="github-skills"></a>

### [GitHub Skills](https://skills.github.com/)

Ejercicios dentro de GitHub para aprender repositorios, ramas y pull requests. Empezar por [Introduction to GitHub](https://github.com/skills/introduction-to-github) y aplicar después el flujo a un proyecto de clase.

`ASIR · DAW · DAM · CE · desarrollo · despliegue · Inicial–Intermedio · EN · lab · Gratis · Oficial`

**Acceso:** cuenta GitHub; los ejercicios usan repositorios y Actions. En repositorios privados se consumen cuotas de Actions. El portal Skills dirige a GitHub Learn; se conserva el enlace al ejercicio. Material principalmente en inglés. **Revisión:** 2026-09-18.

<a id="ibm-skillsbuild"></a>

### [IBM SkillsBuild](https://skillsbuild.org/)

Formación de entrada en tecnología, desarrollo y ciberseguridad. Complemento para adquirir vocabulario y fundamentos antes de abordar documentación o laboratorios más exigentes.

`ASIR · DAW · DAM · desarrollo · defensa · Inicial · ES/EN · teoría · Gratis · Oficial`

**Acceso:** registro; rutas y experiencias disponibles según perfil, programa e idioma. Las credenciales digitales no equivalen por sí mismas a una certificación profesional o título de FP. **Revisión:** 2026-09-18.

<a id="jose-juan-sanchez"></a>

### [José Juan Sánchez Hernández — materiales docentes](https://josejuansanchez.org/)

Materiales y prácticas de FP en español sobre servicios, despliegue y bases de datos. Aportan un contexto de aula especialmente útil para convertir teoría en tareas documentadas.

`ASIR · DAW · DAM · sistemas · despliegue · bases-de-datos · Inicial–Intermedio · ES · teoría · lab · documentación · Gratis · Comunidad`

**Acceso:** consulta abierta; comprobar curso académico, versiones y requisitos de cada práctica. Algunos despliegues pueden usar servicios cloud con coste. **Revisión:** 2026-09-18.

<a id="mdn-learn"></a>

### [MDN Web Docs — Aprende desarrollo web](https://developer.mozilla.org/es/docs/Learn_web_development)

Ruta estructurada de HTML, CSS y JavaScript en español. Referencia sólida para DAW/DAM antes de frameworks; enlaza con la documentación HTTP ya citada en redes.

`DAW · DAM · desarrollo · Inicial–Intermedio · ES/EN · teoría · documentación · Gratis · Oficial`

**Acceso:** lectura pública; priorizar rutas en español y contrastar con inglés si falta una página. **Revisión:** 2026-09-21.

<a id="oracle-academy"></a>

### [Oracle Academy](https://academy.oracle.com/en/oa-web-overview.html)

Currículo y prácticas de Java y bases de datos para enseñanza reglada. Interesa especialmente como recurso de aula para DAW y DAM, y como apoyo en bases de datos para ASIR.

`ASIR · DAW · DAM · desarrollo · bases-de-datos · Inicial–Intermedio · ES/EN · teoría · lab · Condicionado · Oficial`

**Acceso:** recursos gratuitos mediante membresía educativa; el acceso completo del alumnado depende del centro o docente y del programa. No es un catálogo íntegramente abierto para autoinscripción individual. **Revisión:** 2026-09-18.

<a id="postgresql"></a>

### [PostgreSQL Tutorial / Documentation](https://www.postgresql.org/docs/current/index.html)

Documentación oficial de PostgreSQL: SQL, administración, copia de seguridad y configuración. Base para prácticas de datos más allá de tutoriales genéricos; existe [tutorial comunitario](https://www.postgresqltutorial.com/) en inglés como complemento.

`ASIR · DAW · DAM · bases-de-datos · sistemas · Inicial–Avanzado · EN · documentación · lab · Gratis · Oficial`

**Acceso:** docs oficiales públicas en inglés; instalación local o contenedor para practicar sin coste de cloud. El tutorial comunitario no sustituye el manual de la versión usada en clase. **Revisión:** 2026-09-21.
